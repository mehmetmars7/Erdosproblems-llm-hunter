# Economics catalogue: 250 scoped definitions

This batch formalizes the 250 questions in the initial economics research catalogue. It does not claim to enumerate every open problem in economics or to establish first-ever historical priority for every formulation.

The primary-source audit found **45 explicitly stated open questions**, **126 published research agendas**, **78 formulations whose open-question provenance was not verified**, and **one original formulation requiring correction**. Thus 171 records have a verified question or agenda passage; 79 are candidates awaiting provenance or scope review. A source about a topic is not counted as evidence that the precise question was published as open.

Only the EFX existence record reproduces a published mathematical statement in its full specified domain. The other 249 records use adapted or proposed specifications with explicit populations, objects, assumptions, estimands or policy objectives. These additional choices belong to this catalogue, rather than to the cited authors. A model optimization or empirical target is not automatically an unresolved theorem.

Each standalone `.tex` definition contains a mathematical statement, a short English statement, scope and attribution notes, and a numbered bibliography. When an explicit question/agenda source was verified, it is listed first and includes its section, page or abstract locator. Current or supporting sources follow. A missing earliest-reference field means an explicit statement was not verified; it must not be filled with a merely related paper.

`earliest_found` means the earliest explicit statement located and checked in this audit. It is **not a proof of the first historical publication**. No record claims `verified_original`. Undated agendas and unverified formulations use `not_established`. Historical source status and current nonresolution are separate; the preparation date does not certify that no later work has resolved a question.

## Website integration

The category is **Economics** (`economics`, category ID 21). New permanent IDs run from **30007512 to 30007761**, with local numbers `LOCAL-<id>`, no fabricated UnsolvedMath URL, and `published: false`. All existing identities, definitions and display ranks are preserved. The 250 rows are appended to the display order.

The catalogue and detail pages distinguish:

- `open`: the source-authored EFX mathematical statement, with its positive-valued-good convention made explicit.
- `research_question`: 170 scoped formulations based on verified question or agenda passages.
- `provenance_pending`: 79 proposed or corrected formulations requiring further provenance review.

Definitions are statement-only records. They create no research attempt, solution claim, completion estimate or Lean verification claim. The detail page displays subfield, formulation basis, evidence qualification and earliest verified reference.

## Files and reproduction

- `manifest.json`: all 250 formalizations, bibliography metadata, evidence summaries and provenance notes.
- `allocation_report.json`: stable ID assignments and the previous/new watermark.
- `../unsolvedmath/id_registry.json`: preserves the allocation watermark for future imports.
- `../../attacks/open_problems/top_problems/definitions/<id>.tex`: standalone definitions.
- `../../scripts/import_economics_statements.py`: validates metadata, source ordering, reservations and idempotent import; refuses to replace a different existing target.

Run from the repository root:

```bash
python scripts/import_economics_statements.py --check
python -m unittest discover -s tests
for test_file in tests/test_*.js; do node "$test_file" || exit; done
python build_site.py
```

The importer does not merge a branch, deploy the site, or publish records to an external catalogue. Existing main-branch deployment handles generated site data after a reviewed merge.
