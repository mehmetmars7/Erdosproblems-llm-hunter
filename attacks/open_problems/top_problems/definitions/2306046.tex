\section{Research Problems in Function Theory — Problem 6.46}\label{2306046}
{\small\sffamily UnsolvedMath ID 2306046 · Analysis}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


Write $\mathbb D=\{z\in\mathbb C:|z|<1\}$ and $\mathbb T=\partial\mathbb D$. Let $S$ consist of holomorphic injective functions $f(z)=z+\sum_{n\ge2}a_nz^n$ on $\mathbb D$; set $a_0=0$, $a_1=1$. A function in $S$ is starlike if its image is starlike about $0$, and convex if its image is a convex domain.
\paragraph{Statement recorded in the supplied source.}
For every starlike $f\in S$, is $\big||a_{n+1}|-|a_n|\big|\le1$ for all integers $n\ge1$? \sref{2306046}{2}
\subsection{Short English statement}
Historical question: can successive coefficient moduli of a starlike univalent function differ by more than one? The source reports Leung’s affirmative bound.
