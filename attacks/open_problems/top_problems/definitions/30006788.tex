\section*{\texorpdfstring{Exact Asymptotic Waring Function G(k)}{Exact Asymptotic Waring Function G(k)}}\label{30006788}
\subsection{Definitions and mathematical statement}
For $k\ge3$, define
\[
 G(k)=\min\{s\ge1:\ \exists N_0\ \forall N\ge N_0\
 \exists x_1,\ldots,x_s\in{\mathbb{Z}}_{\ge0},\ N=x_1^k+\cdots+x_s^k\}.
\]
The problem is to determine this integer for every $k$. Allowing zero summands is equivalent to using at most $s$ positive powers, but not to requiring exactly $s$ positive powers. The cutoff $N_0$ may depend on $k,s$. This asymptotic function differs from the Waring function that must represent \emph{every} positive integer, including small exceptional values. An exact answer needs both eventual sufficiency and obstructions to every smaller number of summands.
\par\smallskip\textit{Formulation and concept references:} \href{https://dlmf.nist.gov/27.13}{[S1]}.

\subsection{Short English statement}
For each exponent, what is the smallest number of positive powers needed to represent every sufficiently large integer, allowing fewer summands when necessary?
