\section*{Worst-case Subset Sum below the half exponent}\label{30007476}
\subsection{Definitions and mathematical statement}
Let $a_1,\ldots,a_n$ be positive integers, let $t\ge0$, and assume $n\ge2$. The Subset Sum decision asks whether $\sum_{i\in I}a_i=t$ for some $I\subseteq[n]$. Put
\[
 b=\max\{1,\lceil\log_2(1+\max(t,a_1,\ldots,a_n))\rceil\},\qquad
 w=\lceil4(n+b+\log_2(n+2))\rceil.
\]
Use a classical word RAM with $w$-bit words, read-only random-access input, charged word reads and writes, addressing, comparisons, arithmetic, bit operations and shifts. A fresh uniform random word costs one operation, and retained random words occupy writable memory. Seek a single uniform randomized program that halts on every execution, answers correctly with probability at least $2/3$ on every input, and satisfies
\[
 \forall c\in\mathbb N_{\ge1}\ \exists C_c>0,N_c\ \forall n\ge N_c,\ b\le n^c:\quad
 T\le C_c2^{0.49n}
\]
on every random path. All preprocessing is charged, and the program receives no value of $c$.

\subsection{Short English statement}
Can a uniform randomized Subset Sum solver run in $O_c(2^{0.49n})$ word operations for polynomial-bit inputs, using the specified $w$-bit RAM model and one program independent of $c$?
