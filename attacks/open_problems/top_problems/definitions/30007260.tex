\section*{An explicit asymptotic formula for the number of totients}\label{30007260}
\subsection{Definitions and mathematical statement}
\paragraph{Statement recorded in the supplied source.}
Determine a fully specified asymptotic equivalent for
\[
V(x)=\#\{m\leq x:m=\phi(n)\text{ for some positive integer }n\},
\]
counting each distinct totient value once.
\subsection{Short English statement}
Determine a fully specified asymptotic equivalent for the number $V(x)=\#\{m\leq x:m=\phi(n)\text{ for some positive integer }n\}$ of distinct totient values at most $x$, counting each value once.
