\section*{Independent trees}\label{3000045}
{\small UnsolvedMath ID 3000045 · AMR-029-0045 · Combinatorics · AMR Open Problem Lists}
\subsection{Definitions and mathematical statement}
Let $G=(V,E)$ be a finite simple graph with $|V|>k\ge1$.
The graph is $k$-vertex-connected if deletion of fewer than $k$
vertices leaves it connected. Fix any root $r\in V$.
For a spanning tree $T$, write $P_T(r,v)$ for the unique path from
$r$ to $v$.

Spanning trees $T_1,\ldots,T_k$ are independent at $r$ if their paths
to each common destination have disjoint interiors:
\[
 (V(P_{T_i}(r,v))\setminus\{r,v\})\cap
 (V(P_{T_j}(r,v))\setminus\{r,v\})=\varnothing
                      \quad(v\ne r,\ i\ne j).
\]
Does every $k$-vertex-connected graph have such a family for every
choice of root and every $k$?

The root and destination are permitted common endpoints. The trees
are not required to be vertex-disjoint, since each spans all of $V$,
and they need not be edge-disjoint as whole subgraphs. The comparison
is between paths to the same destination from the one fixed root.
Requiring analogous independence for paths between every pair of
vertices is a stronger, different property. A separate collection
of disjoint paths for each destination, supplied by vertex connectivity,
does not guarantee consistency of those path collections as spanning
trees. It is that simultaneous consistency the conjecture demands.
\subsection{Short English statement}
Does $k$-vertex-connectivity guarantee $k$ spanning trees whose
paths from any prescribed common root have pairwise disjoint interiors at each destination?
