\section{The Babai Conjecture on Graph Isomorphism}\label{1156}
{\small\sffamily UnsolvedMath ID 1156 · Algebra}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


A finite simple graph is \(G=(V,E)\), where \(E\) is a set of
unordered pairs of distinct vertices.  Two graphs \(G,H\) are
isomorphic if there is a bijection \(\phi:V(G)\to V(H)\) with
\[
 \{u,v\}\in E(G)\ \Longleftrightarrow\
 \{\phi(u),\phi(v)\}\in E(H).
\]
Use an adjacency-matrix encoding.  A quasipolynomial bound is
\(\exp((\log N)^{O(1)})\), where \(N\) is the total number of input
vertices; the exponent is an absolute constant, independent of the graphs.
\paragraph{Statement recorded in the supplied source.}
Is there a deterministic algorithm deciding whether any two
finite graphs are isomorphic in worst-case time
\[
 \exp\bigl(C(\log(N+2))^c\bigr)
\]
for absolute constants \(C,c>0\)?
This recorded quasipolynomial target is achieved by Babai's algorithm;
it does not ask for a polynomial-time bound. \sref{1156}{2}
\subsection{Short English statement}
Can isomorphism of arbitrary finite graphs be decided in quasipolynomial time? Babai's cited algorithm attains this historical target.
