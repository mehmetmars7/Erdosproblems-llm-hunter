\section{Finding k-edge-outerplanar graph embeddings}\label{3113}
{\small\sffamily UnsolvedMath ID 3113 · Graph Theory}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


Let $G$ be a finite planar graph. For a plane embedding $\mathcal E$, remove simultaneously all edges incident with the unbounded face, retain the inherited embedding, and repeat until no edges remain. Write $p(\mathcal E)$ for the number of rounds and $p(G)=\min_{\mathcal E}p(\mathcal E)$; an edgeless graph has $p(G)=0$.
\paragraph{Statement recorded in the supplied source.}
Is there a polynomial-time algorithm which, given $G$, constructs a plane embedding $\mathcal E$ satisfying $p(\mathcal E)=p(G)$? \sref{3113}{2}
\subsection{Short English statement}
Can an embedding with the minimum number of edge-peeling layers be found in polynomial time?
