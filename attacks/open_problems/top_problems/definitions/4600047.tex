\section*{Surjunctive groups}\label{4600047}
{\small UnsolvedMath ID 4600047 · AMR-045-0047 · Dynamical Systems · AMR Open Problem Lists}
\subsection{Definitions and mathematical statement}
Let $G$ be a countable discrete group. For every finite nonempty
alphabet $A$, give $A^G$ its product topology and the left
shift action
\[
                   (g\cdot x)(h)=x(g^{-1}h).
\]
A cellular automaton on $A^G$ is a continuous equivariant map
$F:A^G\to A^G$. Equivalently, there is a finite memory set
$D\subset G$ and a rule $\varphi:A^D\to A$ with
$(Fx)(h)=\varphi((x(hd))_{d\in D})$.
The group is called surjunctive if for every finite $A$ and
every such $F$,
\[
                       F\text{ injective}\quad\Longrightarrow\quad
                       F\text{ surjective}.
\]

Characterize the countable groups with this property. In
particular, determine whether all countable groups are
surjunctive, or whether there is a group, finite alphabet, and
local rule which give an injective non-onto map of the full
shift.

The map need not preserve any algebraic structure on the
alphabet. Injectivity and surjectivity concern all configurations,
not only finitely supported or periodic ones. A countable group
need not be finitely generated or come with a finite presentation,
so the classification is a group-theoretic one and is not
restricted to algorithmically specified groups. The same group
must satisfy the implication uniformly for every finite alphabet
and every memory set; checking one selected automaton does
not establish surjunctivity.
\subsection{Short English statement}
Which countable groups force every injective finite-state cellular automaton to be onto?
