\paragraph{Statement recorded in the supplied source.}
Let $A\subseteq \mathbb{N}$ be a set such that $\lvert A\cap [1,x]\rvert=o(x^{1/2})$. Let $ B=\{ n\geq 1 : a\nmid n\textrm{ for all }a\in A\}. $ If $B=\{b_1<b_2<\cdots\}$ then is it true that $ \lim \frac{1}{x}\sum_{b_i<x}(b_{i+1}-b_i)^2 $ exists (and is finite)? \sref{2143}{1}

\paragraph{Scope and interpretation.}

The source contains a broken negated-divisibility escape. The surviving set is the set avoiding all indicated multiples. Degenerate finite surviving sets require the usual empty-gap-sum convention. \sref{2143}{1}

\subsection{Short English statement}

When the forbidden divisors form a set sparser than square-root growth, must the normalized squared gaps between surviving integers have a finite limit?
