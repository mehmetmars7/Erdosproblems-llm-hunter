\section*{O19 — Finding a primitive root modulo a prime}\label{8400022}
{\small UnsolvedMath ID 8400022 · AMR-083-0022 · Graph Theory · AMR Open Problem Lists}
\subsection{Definitions and mathematical statement}
Let $p$ be a prime. A primitive root modulo $p$ is an integer $g$ with $1\le g<p$ such that
\[
\{g^j\bmod p:0\le j<p-1\}=\{1,\ldots,p-1\}.
\]
Equivalently, $g$ has multiplicative order $p-1$ in $\mathbb F_p^\times$. Such an element exists because this finite multiplicative group is cyclic; for $p=2$ the value $g=1$ qualifies.

Does there exist a deterministic classical algorithm which, on every binary prime input $p$, outputs a primitive root using a number of bit operations bounded by a fixed polynomial in $\ell(p)=\lfloor\log_2p\rfloor+1$? The output may be any primitive root, with no minimality requirement.

Only $p$ is provided. In particular, a complete factorization of $p-1$, useful for checking candidate orders, is not included in the input. All preliminary computations needed for the construction are charged to the same running-time bound. The primality of $p$ may be treated as a promise.

The task is stronger than producing a polynomially sized list known merely to contain a primitive root, unless the algorithm can identify a successful member within the required time. A proof that many residues generate the group also does not itself give deterministic selection. The aim is an unconditional uniform search procedure for individual arbitrary primes, in the classical bit model.
\subsection{Short English statement}
Can a primitive root modulo every prime be found deterministically in time polynomial in the prime’s binary length?
