\section{1/3-2/3 Conjecture}\label{1488}
{\small\sffamily UnsolvedMath ID 1488 · Combinatorics}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


A finite poset \((P,\le_P)\) is a finite set with a reflexive,
antisymmetric, transitive order. It is a chain if every two elements
are comparable. A linear extension is a total order on \(P\) in
which \(x\) precedes \(y\) whenever \(x<_P y\).
Let \(\mathcal L(P)\) be the finite nonempty set of its linear
extensions, equipped with the uniform probability distribution.
For distinct \(x,y\in P\), put
\[
 b_P(x,y)=\frac{\#\{L\in\mathcal L(P):x\text{ precedes }y\text{ in }L\}}
                  {|\mathcal L(P)|}.
\]
\paragraph{Statement recorded in the supplied source.}
For every finite poset \(P\) which is not a chain, are there
distinct \(x,y\in P\) satisfying
\[
                 \frac13\le b_P(x,y)\le\frac23?
\] \sref{1488}{2}
\subsection{Short English statement}
Does every finite partially ordered set with an incomparable pair have two elements whose relative order occurs with probability between one-third and two-thirds in a uniformly chosen linear extension?
