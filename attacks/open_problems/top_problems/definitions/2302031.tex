\section{Research Problems in Function Theory — Problem 2.31}\label{2302031}
{\small\sffamily UnsolvedMath ID 2302031 · Analysis}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


Let $A,B\subset\mathbb C$ be countable dense sets; density means that every nonempty open disc meets the set. For a function $f$, $f^{-1}(B)=\{z:f(z)\in B\}$.

\paragraph{Statement recorded in the supplied source.}
For every such pair $A,B$, does there exist an entire function $f$ such that
\[f^{-1}(B)=A?\]
If the universal assertion is false, determine conditions on $A,B$ under which it holds. \sref{2302031}{2}
Update 2.31 records Barth and Schneider's affirmative construction. This question is about the inverse-image identity; it does not additionally require $f(A)=B$. \sref{2302031}{2}
\subsection{Short English statement}
Can an entire function arrange that membership of its value in one prescribed dense countable set occurs exactly on another prescribed dense countable set?
