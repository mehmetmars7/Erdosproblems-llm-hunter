\section*{O14 — Square roots modulo a prime}\label{8400016}
{\small UnsolvedMath ID 8400016 · AMR-083-0016 · Graph Theory · AMR Open Problem Lists}
\subsection{Definitions and mathematical statement}
Let $p$ be a prime and $a\in\mathbb F_p$, represented by an integer $0\le a<p$. The input is promised to satisfy $a=x^2$ for at least one $x\in\mathbb F_p$. A valid output is any representative $x\in\{0,\ldots,p-1\}$ with
\[
x^2\equiv a\pmod p.
\]
For $a=0$ the answer is zero, and for $p=2$ the answer is immediate. When $p$ is odd and $a\ne0$, either of the two opposite roots is acceptable.

Is there a deterministic classical algorithm that produces such a root on every promised input using a number of bit operations bounded by a fixed polynomial in $\ell(p)+\ell(a+1)$? The prime and the residue vary together; in particular, an algorithm for one fixed modulus does not supply the required uniform result.

No quadratic nonresidue, factorization of $p-1$, or other preprocessing specific to $p$ is included in the input. Any work to obtain useful auxiliary data must be counted. Verifying a candidate root is efficient, but verification is distinct from constructing one. The target is a worst-case unconditional deterministic bound, so a random trial procedure or an algorithm whose analysis assumes an unproved hypothesis does not by itself settle the question. The requested output is one root, rather than a symbolic description of all possible roots.
\subsection{Short English statement}
Can a square root of every promised quadratic residue modulo a prime be constructed deterministically in polynomial time?
