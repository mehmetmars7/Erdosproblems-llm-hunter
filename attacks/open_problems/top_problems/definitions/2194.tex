\paragraph{Statement recorded in the supplied source.}
What is the maximum number of edges that a graph on $n$ vertices can have if it does not contain two edge-disjoint cycles with the same vertex set? \sref{2194}{1}

\subsection{Short English statement}

How many edges can a graph have without containing two edge-disjoint cycles that visit exactly the same set of vertices?
