\section{Research Problems in Function Theory — Problem 9.10}\label{2309010}
{\small\sffamily UnsolvedMath ID 2309010 · Analysis}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


Let $n\ge2$ and $F\subset\mathbb R^n$ be closed, possibly unbounded. A real function on an open set is harmonic if it is twice continuously differentiable and its Laplacian is zero. Call $F$ a set of harmonic approximation if for every $g\in C(F;\mathbb R)$ harmonic on $F^{\circ}$ and every $\varepsilon>0$, there is a function $h$ harmonic on all of $\mathbb R^n$ with \[\sup_{x\in F}|g(x)-h(x)|<\varepsilon.\]
\paragraph{Statement recorded in the supplied source.}
Give necessary and sufficient conditions on $F$ for it to be a set of harmonic approximation in every dimension $n\ge2$. \sref{2309010}{2}
\subsection{Short English statement}
Characterize the closed sets on which continuous interior-harmonic functions admit arbitrarily accurate uniform approximation by globally harmonic functions.
