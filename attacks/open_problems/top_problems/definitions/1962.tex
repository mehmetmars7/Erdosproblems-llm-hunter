\section{Local Increments of the Sidon Extremal Function}\label{1962}

{\small\sffamily UnsolvedMath ID 1962 · Combinatorics}

A Sidon set has $a+b=c+d$ only when the multisets $\{a,b\}$ and $\{c,d\}$ agree. Equal summands are allowed, but interchanging their order is not a new representation. Unless a real or group domain is explicitly specified, the set here consists of integers. \sref{1962}{1} \sref{1962}{2}

\paragraph{Statement recorded in the supplied source.}
Let $F(N)$ be the size of the largest Sidon subset of $\{1,\ldots,N\}$. Is it true that for every $k\geq 1$ we have $ F(N+k)\leq F(N)+1 $ for all sufficiently large $N$? \sref{1962}{1}

\subsection{Short English statement}

Can extending a sufficiently long integer interval by any fixed length increase its maximum Sidon-set size by more than one?
