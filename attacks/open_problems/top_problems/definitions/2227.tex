\paragraph{Statement recorded in the supplied source.}
Is there some function $f$ such that for all $k\geq 3$ if a finite graph $G$ has chromatic number $\geq f(k)$ then $G$ must contain some odd cycle whose vertices span a graph of chromatic number $\geq k$? \sref{2227}{1}

{\small\emph{Transcription note.} Only unambiguous escape/formatting damage and nonmathematical serialization debris were repaired in the displayed source statement.}

\subsection{Short English statement}

Does sufficiently large chromatic number force an odd cycle whose vertices induce a graph of any prescribed chromatic number?
