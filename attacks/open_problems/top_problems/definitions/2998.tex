\section{Kirby Problem 4.122}\label{2998}
{\small\sffamily UnsolvedMath ID 2998 · Topology}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


Work in the smooth category with compact orientable manifolds and smoothly embedded branch surfaces, following the original construction. A finite branched covering $p:W\to N$ with branch locus $F\subset N$ is an ordinary finite covering off $F$, with local topological model $(z_1,z_2)\mapsto(z_1^e,z_2)$ along the branch surface; degrees and branching indices may depend on $W$, and simplicity is not required. The branch locus is the image of the singular set. A properly embedded compact surface $F\subset B^4$ is ribbon if the radial function restricts to a Morse function with no local maximum in its interior. Call $F$ universal in $B^4$ when every compact orientable smooth four-manifold built from $B^4$ by attaching only one- and two-handles is a finite branched cover of $B^4$ with branch locus exactly $F$. A universal link $L\subset S^3$ is a fixed smooth link such that every closed orientable three-manifold is a finite cover of $S^3$ branched over exactly $L$. \sref{2998}{3}
\paragraph{Statement recorded in the supplied source.}
Is there a single smoothly embedded surface $S\subset S^4$, allowed to be disconnected, such that every closed orientable smooth four-manifold $W$ admits a finite branched covering $W\to S^4$ with branch locus exactly $S$? In the associated questions, does a connected universal surface exist in $B^4$, and which universal links in $S^3$ occur as $\partial F$ for universal surfaces $F\subset B^4$? \sref{2998}{2}\sref{2998}{3}
\subsection{Short English statement}
Can one fixed surface in the four-sphere serve as the branch locus for every closed orientable smooth four-manifold? Also seek connected universal surfaces in the four-ball and characterize which universal three-dimensional links bound universal surfaces.
