\section{Sunflower Conjecture}\label{1490}
{\small\sffamily UnsolvedMath ID 1490 · Combinatorics}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


An \(r\)-petal sunflower is a collection of distinct sets
\(S_1,\ldots,S_r\) whose pairwise intersections all equal a
single set \(C\): \(S_i\cap S_j=C\) for \(i\ne j\).
Thus \(C=\bigcap_i S_i\) is the core, and the petals \(S_i\setminus C\)
are pairwise disjoint. The core may be empty.
A \(k\)-uniform set family on a finite ground set \(X\) is a family
\(\mathcal F\subseteq\{S\subseteq X:|S|=k\}\), without repeated sets.
\paragraph{Statement recorded in the supplied source.}
For every fixed integer \(r\ge3\), does there exist a constant
\(C_r>1\) such that, for every integer \(k\ge1\), every finite ground set
\(X\), and every \(k\)-uniform family \(\mathcal F\) on \(X\),
\[
       |\mathcal F|\ge C_r^{k}
       \quad\Longrightarrow\quad
       \mathcal F\text{ contains an }r\text{-petal sunflower}?
\] \sref{1490}{2}
\subsection{Short English statement}
For each fixed number of petals, does an exponential bound in set size force a sunflower in every sufficiently large family of distinct equally sized sets?
