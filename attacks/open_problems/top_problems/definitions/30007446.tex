\section*{FPRAS for common integer polymatroid bases}\label{30007446}
\subsection{Definitions and mathematical statement}
\paragraph{Statement recorded in the supplied source.}
Given value oracles for two integer polymatroid rank functions on n elements with binary-encoded capacities and compatible base totals, can one estimate the number of common nonnegative integral base vectors within relative error $\varepsilon $ and failure $\delta $ using polynomially many oracle calls and bit operations in n, total encoding length, $\varepsilon ^{-1}$ and $\log (\delta ^{-1})$, including a certain zero answer for emptiness?
