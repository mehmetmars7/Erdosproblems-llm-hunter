\paragraph{Statement recorded in the supplied source.}
Let $t\geq 1$ and $A\subseteq \{1,\ldots,N\}$ be such that whenever $a,b\in A$ with $b-a\geq t$ we have $b-a\nmid b$. How large can $\lvert A\rvert$ be? Is it true that $ \lvert A\rvert \leq \left(\frac{1}{2}+o_t(1)\right)N? $ \sref{2225}{1}

\paragraph{Residual task reported by the archive.}

The embedded review (2026-08-17) records: Determine the true excess above N/2 for fixed t, especially t=2, rather than only an o(N) error. \sref{2225}{1}

\subsection{Short English statement}

If sufficiently large differences between chosen integers never divide the larger integer, can the chosen set exceed half the interval asymptotically?
