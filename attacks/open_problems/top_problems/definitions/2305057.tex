\section{Research Problems in Function Theory — Problem 5.57}\label{2305057}
{\small\sffamily UnsolvedMath ID 2305057 · Analysis}
\subsection{Definitions and mathematical statement}

\paragraph{Shared notation.}$\mathbb N=\{1,2,\ldots\}$, and $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ denote the integers, rationals, reals and complex numbers. Any other conventions are specified locally.


Let $\mathbb D=\{z\in\mathbb C:|z|<1\}$ and $\mathbb T=\partial\mathbb D$. A Stolz angle with vertex $\zeta\in\mathbb T$ is an open angular approach region inside $\mathbb D$ whose sides approach $\zeta$ strictly within the inward half-plane; it may be truncated arbitrarily close to its vertex. An angular limit is a common spherical limit through every such non-tangential region. A set $E\subset\mathbb C$ has zero logarithmic capacity if each compact $K\subset E$ has capacity zero; for compact $K$, \[\operatorname{cap}(K)=\exp\left(-\inf_{\mu\in\mathcal P(K)}\iint\log\frac1{|z-w|}\,d\mu(z)d\mu(w)\right),\] with value $0$ when the infimum is $+\infty$, where $\mathcal P(K)$ is the set of probability measures supported on $K$. Almost every boundary point means arc-length almost every point.
\paragraph{Statement recorded in the supplied source.}
For every analytic $f:\mathbb D\to\mathbb C$, can the dense-image alternative in Plessner’s theorem be strengthened? In particular, is it true that for almost every $\zeta\in\mathbb T$, either $f$ has an angular limit at $\zeta$, or for every Stolz angle $S$ at $\zeta$ the omitted set $\mathbb C\setminus f(S)$ has zero logarithmic capacity? \sref{2305057}{2}
\subsection{Short English statement}
Can Plessner’s almost-everywhere dichotomy be sharpened so that every Stolz-angle image omits only a set of logarithmic capacity zero?
