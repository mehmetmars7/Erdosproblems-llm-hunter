\section*{Uniform quasipolynomial worst-case trace reconstruction}\label{30007491}
\subsection{Definitions and mathematical statement}
\paragraph{Statement recorded in the supplied source.}
For binary strings of known length n and fixed rational retention probability $p>0$, can one uniform randomized multitape algorithm reconstruct every input string with success $\geq 2/3$ using $\exp (O_p((\log $ $n)^{3}(1+\log $ $\log (2n))^{6}))$ independent deletion traces and bit time polynomial in n, the binary length of p and the trace budget, on every trace stream and random-bit path?
