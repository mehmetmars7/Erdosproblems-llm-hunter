\section{Large Sidon Subsets under a Four-Point Difference Condition}\label{2291}

{\small\sffamily UnsolvedMath ID 2291 · Number Theory}

\subsection{Definitions and mathematical statement}

fields, $[N]=\{1,\ldots,\lfloor N\rfloor\}$, and $\log$ is the natural

$f\gg g$ reverses this comparison; $f=o(g)$ means $f/g\to0$;

A Sidon set has $a+b=c+d$ only when the multisets $\{a,b\}$ and $\{c,d\}$ agree. Equal summands are allowed, but interchanging their order is not a new representation. Unless a real or group domain is explicitly specified, the set here consists of integers. \sref{2291}{1} \sref{2291}{2}

\paragraph{Statement recorded in the supplied source.}
Let $A\subset \mathbb{R}$ be a set of size $n$ such that every subset $B\subseteq A$ with $\lvert B\rvert =4$ has $\lvert B-B\rvert\geq 11$. Find the best constant $c>0$ such that $A$ must always contain a Sidon set of size $\geq cn$. \sref{2291}{1}

\paragraph{Residual task reported by the archive.}

The embedded review (2026-08-17) records: Determine c\_* or further narrow the interval [9/17,4/7]. \sref{2291}{1}

\subsection{Short English statement}

What proportion of a real set can always be retained as a Sidon subset when every four points already determine sufficiently many differences?
