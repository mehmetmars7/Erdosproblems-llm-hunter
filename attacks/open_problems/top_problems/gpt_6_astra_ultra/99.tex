\section*{\texorpdfstring{L versus NL}{L versus NL}}\label{99}
\subsection{Definitions and mathematical statement}
The classes $\mathsf L$ and $\mathsf{NL}$ use deterministic and nondeterministic $O(\log n)$ work space, respectively, with a read-only input tape. In nondeterministic acceptance, a yes-input has an accepting branch and a no-input has none. The equivalent graph problem asks for a deterministic logarithmic-space algorithm deciding whether
\[
 \exists\text{ directed path }s\leadsto t\text{ in }G.
\]
The graph is arbitrary and directed. Undirected connectivity, extra work space, or a nonuniform circuit procedure does not settle this target.
\par\smallskip\textit{Formulation and concept references:} \href{https://drops.dagstuhl.de/storage/00lipics/lipics-vol099-socg2018/LIPIcs.SoCG.2018/LIPIcs.SoCG.2018.pdf}{[S1]}.

\subsection{Short English statement}
Can nondeterministic logarithmic-space computation always be simulated with the same asymptotic amount of deterministic working memory?
\subsection{Research attempt}
\paragraph{Process and exact remaining gap.}
This attempt was generated by GPT-6 Astra Ultra on 27 September 2026. It develops a deterministic reachability procedure whose work space depends on the number of branching vertices, proves a separate Eulerian-graph subcase, and checks both against exhaustive finite graphs. These are elementary restricted results and uses of established theorems, not a new resolution of the general problem.

The first missing step in the main route is removing the number-of-branching-vertices term from the bound
\[
 O(b+\log N),\qquad
 b=\#\{v:\deg^+(v)\ge2\},
 \tag{99.1}
\]
for a directed graph with $N$ explicitly represented vertices. For arbitrary graphs $b$ can be of order $N$. A logarithmic-space procedure for the compressed graph in that generality is not supplied. All logarithms are binary, the graph encoding allows random access by rescanning the read-only input, and $N\ge2$; smaller graphs are handled directly.

\paragraph{Literature and the standard baseline.}
Reingold proves deterministic logarithmic-space connectivity for undirected graphs [E1]. The distinctions between directed reachability, its $\mathsf{NL}$-completeness, and Savitch's deterministic $O(\log^2 N)$ simulation are set out in [E2, Chapter 4]. The geometric restrictions appearing in [S1] are not assumed here. We give the relevant recurrence explicitly so that the extra logarithmic factor cannot disappear through notation.

Let $R_i(u,v)$ mean that a directed path of length at most $2^i$ goes from $u$ to $v$. With $R_0(u,v)$ testing equality or an edge,
\[
 R_i(u,v)=\bigvee_{z=1}^{N}
     \bigl(R_{i-1}(u,z)\wedge R_{i-1}(z,v)\bigr).
 \tag{99.2}
\]
Splitting a path proves the forward implication; concatenating the two subpaths proves the reverse. At $i=\lceil\log N\rceil$, the bound covers a simple path whenever any path exists. A recursive deterministic evaluation stores the endpoints, midpoint-loop counter, and control state in $O(\log N)$ bits at each of $O(\log N)$ levels. The resulting bound is $O(\log^2 N)$. Reusing the workspace of completed recursive calls does not remove information in the still-active callers.

\paragraph{Functional paths need only logarithmic space.}
If every vertex has outdegree at most one, a path from $s$ has no choices. Store the current vertex and a counter up to $N$. At each step accept if the vertex is $t$, otherwise follow its unique successor or reject if none exists. After $N$ transitions without finding $t$, a vertex has repeated and the orbit will cycle forever, so reject. The vertex and counter use $O(\log N)$ bits; the unique successor is found by scanning the adjacency encoding. Self-loops and zero-length paths are included.

The next construction contracts only stretches where this argument applies. It does not assume that an arbitrary graph has a small number of such stretches.

\paragraph{Compression at branching vertices.}
Let $B$ be the set of vertices of outdegree at least two and put
\[
 Q=B\cup\{s,t\},\qquad q=|Q|\le b+2.
\]
Construct an implicit directed graph $H$ on $Q$. For each $u\in Q$ and each original edge $u\to z$, follow the unique-successor chain from $z$ as long as its current vertex is outside $Q$. Stop on entering $Q$, at a vertex of outdegree zero, or after $N$ steps without entering $Q$. In the first case add an edge from $u$ to that first vertex of $Q$; in the other cases add none. Stop at $t$ if it is encountered, regardless of its original successors. The counter cutoff is sound because a repeated vertex outside $Q$ forces an endless functional cycle outside $Q$.

\emph{Lemma.} There is a path $s\leadsto t$ in $G$ if and only if there is one in $H$.

\emph{Proof.} Each edge of $H$ records an actual finite path segment in $G$, so an $H$-path expands to a $G$-path. Conversely take any finite $G$-path from $s$ to its first occurrence of $t$ and split it at visits to $Q$. Between visits every vertex has outdegree at most one, so each segment is exactly one of the chains used in the construction. This yields an $H$-walk from $s$ to $t$, and hence a path. The zero-length case $s=t$ is accepted before construction. \hfill$\square$

\paragraph{Space accounting without a hidden table of labels.}
The set $Q$ is not stored as $q$ vertex labels, which would cost $O(q\log N)$ bits. Instead order its vertices by their original labels. To obtain its $j$th member, rescan all labels, test outdegree by scanning the input, and count how many belong to $Q$. This uses only $O(\log N)$ additional bits. Similarly compute the index in $Q$ of an encountered vertex by rescanning labels.

Store two bit vectors of length $q$, initially marking only $s$. In a round, copy the current vector to the next vector; for every marked vertex scan its outgoing edges in $H$ using the chain procedure and mark their endpoints in the next vector. Replace the old vector after the full round. After $q$ rounds the set is exactly the reachable set, since a reachable vertex has a simple path of length at most $q-1$ in $H$.

The two bit vectors use $2q$ bits. Only a fixed number of original vertex labels, ordinal counters, edge counters, and chain counters is simultaneously active; each costs $O(\log N)$. Thus the total is (99.1). All rescans and chain walks have polynomially many iterations, and the nesting depth of these loops is fixed. The procedure has polynomial time as well as the stated space bound.

For every fixed constant $c$, this gives a deterministic logarithmic-space algorithm on graphs satisfying $b\le c\log N$. It can be made a total-language algorithm: first count branching vertices, reject encodings violating that restriction, then run the procedure. The constant $c$ is fixed for the language, not selected separately for each input. A graph with few branching vertices may still have long paths and many merging vertices; those features are allowed.

\paragraph{A different restricted family: balanced directed graphs.}
Suppose every vertex satisfies $\deg^+(v)=\deg^-(v)$. Then every weakly connected component is strongly connected. To prove this, contract strongly connected components to obtain an acyclic directed graph. For any contracted component $C$, summing the original degree differences over its vertices gives
\[
 \#\{\text{edges leaving }C\}
 =\#\{\text{edges entering }C\},
 \tag{99.3}
\]
because internal edges cancel. In a weak component of the condensation graph take a source. It has no incoming edges, so (99.3) gives no outgoing edges either. Weak connectivity forces it to be the whole weak component. Therefore the condensation has no edges and the claim follows.

Consequently, on these balanced graphs, $s\leadsto t$ holds exactly when $s,t$ are connected after edge orientations are forgotten. Degree balance can be checked by scanning the input with logarithmic counters. The undirected adjacency predicate is evaluated by rescanning the original encoding, so Reingold's algorithm [E1] gives a logarithmic-space decision procedure. Disconnected graphs and self-loops cause no difficulty. This is a use of the established undirected theorem after a proved structural reduction, not an extension of that theorem to arbitrary directed inputs.

\paragraph{Countertests for extending the two reductions.}
Forgetting orientations without balance is invalid: in the graph $a\to b\leftarrow c$, vertices $a,c$ are weakly connected but $a$ does not reach $c$. Equation (99.3) fails for the relevant strongly connected components. Adding reverse edges changes the answer to the original question.

The branching compression also stops at a real obstruction. In a graph where most vertices have two successors, $Q$ is essentially the entire graph, and its reachability bit vector has linear size. The lemma is still correct, but the desired space bound is gone. Replacing the vector by a recursive query for whether a vertex is marked leads back to retaining nested subproblems, as in (99.2). Neither the correctness of compression nor the success of the functional case bounds this recursive memory.

A guessed path of length at most $N-1$ uses only a vertex and a counter along one nondeterministic branch. A deterministic search must establish that some branch succeeds, or all fail, with controlled memory. The branching lemma solves that coordination problem only when the complete compressed reachable set fits in logarithmic space. It does not transform the existential path witness into a deterministic selector in general.

\paragraph{Verification and outcome.}
The exact verification script compares compressed and ordinary reachability for every ordered pair in every directed graph on up to four labelled vertices, including loops. It separately checks the weak/strong connectivity equivalence for every balanced graph in that collection and tests the asymmetric three-vertex counterexample. These checks test graph lemmas; they do not establish a complexity-class equality. The memory proof is given separately, since a Python implementation with ordinary sets is not itself a logarithmic-space implementation.

\textbf{UNRESOLVED.} We obtain deterministic $O(b+\log N)$ space and polynomial time for the branching compression, and logarithmic space for balanced graphs using Reingold's theorem. Arbitrary directed reachability still lacks a deterministic logarithmic-space algorithm in this attempt, and no separating language is constructed.
