\subsection{Mathematical statement of the claimed result}
\paragraph{Manuscript 1.}
The input comprises positive integers $a_1,\ldots,a_n$ and a nonnegative integer $t$, with $n\ge2$; the question is whether $\sum_{i\in I}a_i=t$ for some subset $I$. Define
\[
 b=\max\{1,\lceil\log_2(1+\max(t,a_1,\ldots,a_n))\rceil\},\qquad
 w=\lceil4(n+b+\log_2(n+2))\rceil.
\]
The model has read-only random-access input and counted writable $w$-bit words, unit-cost word arithmetic and addressing, and unit-cost fresh random words; all stored randomness and preprocessing are charged. A single uniform algorithm has no false positive and accepts each positive instance with probability at least $2/3$. For every fixed integer $c\ge1$ there exist $A_c,k_c,N_c$ such that $n\ge N_c$ and $b\le n^c$ imply, on every random execution,
\[
 T\le A_c n^{k_c}2^{n/2},\qquad S\le A_c(n+b+2)^{15}2^{0.199n}
\]
in operations and writable words, respectively. The algorithm itself does not depend on $c$.
