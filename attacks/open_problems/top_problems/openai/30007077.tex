\paragraph{Mathematical claim 1.} For a smooth connected projective complex variety $B$, an algebraic vector bundle $E$ of rank $r\ge2$, and $X=\mathbb P_B(E)$ parametrizing lines in the fibers, OpenAI claims
\[
\bigl[L_k^B Z_B=0\text{ for all }k\ge-1\bigr]\ \Longrightarrow\
\bigl[L_k^X Z_X=0\text{ for all }k\ge-1\bigr].
\]
For each target $Y$, $Z_Y$ is its ordinary descendant partition function $\exp(\sum_g\hbar^{g-1}F_g^Y)$ with all cohomology classes, stable-map cotangent classes and actual effective integral curve labels. The conclusion is coefficientwise in every genus, curve class and descendant list.
