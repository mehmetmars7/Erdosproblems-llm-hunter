\section*{Uniform finite-metric randomized k-server implementation}

\subsection{OpenAI's claim}
OpenAI presents the following claims relevant to this question, with manuscript numbers following paper order in Sources. In manuscript 1 (family 110; 2026-09-24), the asserted result is that finite rational metrics admit a uniform randomized $k$-server implementation with that ratio, polynomial preprocessing and per-request bit cost, and a finite instance-dependent additive allowance.

\subsection{Mathematical statement of the claimed result}
\paragraph{Manuscript 1.}
For integers $n\ge3$ and $2\le k<n$, equip $X=[n]$ with a metric $d$ having rational distances. Choose an initial labeled server tuple $s\in X^k$, allowing repetitions. With full binary input length $L$, the claim supplies one uniform randomized online algorithm, absolute $C$ and a polynomial $p$, whose preprocessing costs at most $p(L)$ and whose response to request $r_t$, on every reachable history and internal state, costs at most
\[
 p(L+\lceil\log_2(t+1)\rceil)
\]
additional bit operations. It uses unbiased bits and moves one selected server to each request, allowing a zero-distance move. For any finite $\sigma$ fixed before the random bits are chosen,
\[
 \mathbb E\operatorname{cost}_{A,s}(\sigma)
 \le C(\log(k+1))^2\operatorname{OPT}_s(\sigma)+B_{d,k,s},
\]
where $\operatorname{OPT}$ is the minimum offline movement cost and $B_{d,k,s}<\infty$ is independent of $\sigma$ and its horizon. The algorithm does not need the horizon in advance.
