\section*{Kourovka Notebook Problem 21.146}

\subsection{OpenAI's claim}
The linked manuscripts present the following claims by OpenAI: One group of type $F_\infty$ is claimed to contain every finitely presented group, with finitely generated subgroups exactly the recursively presented ones; Such a group is also claimed to embed in a simple group of type $F_\infty$. Together they give a claimed affirmative answer in the matching scope.

\subsection{Outline of the argument}
A universal finite presentation is inserted into faithful finite diagram envelopes using two systems of idempotents. An ascending-torus construction supplies uniform fillings with finitely many simplex types in each dimension, establishing the claimed higher finiteness of the universal envelope.

Encoded finite diagrams carry faithful actions with controlled stabilizers. A homological device for ascending tori provides fillings in every dimension, and stabilizers of finite type in a highly transitive action assemble the simple overgroup while retaining higher finiteness.

\subsection{Scope relative to this problem}
Every F\_\{n-1\} input is finitely presented. Theorem 1.1 embeds all these inputs in the same F\_infinity group, stronger than allowing a different target per input or per n. The simple F\_infinity overgroup theorem supplies the requested improvement for input groups with decidable word problem. The record includes groups with undecidable word problem and, in the bundles, additional homological/pro-p/TDLC targets. The claimed conclusion supplies the requested case and extends it in the directions just specified.

\subsection{Formal verification}
