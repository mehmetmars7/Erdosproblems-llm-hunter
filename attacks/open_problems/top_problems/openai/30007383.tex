\section*{A limiting density threshold for every fixed random clause size}

\subsection{OpenAI's claim}
OpenAI presents a proof in the selected manuscript. Each fixed random clause size $k\geq3$ is claimed to have a positive finite limiting satisfiability threshold; the manuscript credits an earlier resolution by Carenini.

\subsection{Mathematical statement of the claimed result}
\paragraph{Result 1.} Fix integer \(k\ge3\). Sample independent proper \(k\)-clauses with replacement, choosing \(k\) distinct variables uniformly and each literal sign uniformly. If \(P_n(m)\) denotes the satisfiability probability, the source claims a finite positive constant \(\alpha_k\) with
\[
 \lim_{n\to\infty}P_n(\lfloor cn\rfloor)=
 \begin{cases}1,&0\le c<\alpha_k,\\0,&c>\alpha_k.\end{cases}
\]
No value at \(c=\alpha_k\), or numerical formula for \(\alpha_k\), is part of this theorem.
