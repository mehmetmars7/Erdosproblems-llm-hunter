\section*{QAOA reaches the SK ground value when thermodynamic size is taken first}

\subsection{OpenAI's claim}
OpenAI presents a proof in the selected manuscript. QAOA is claimed to approach the SK ground-energy density when system size goes to infinity before depth, using deterministic disorder-independent angles but no effective depth bound.

\subsection{Mathematical statement of the claimed result}
\paragraph{Result 1.} For independent standard Gaussian \(J_{ij}\), set \(C_{n,J}=n^{-1/2}\sum_{i<j}J_{ij}Z_iZ_j\) and \(B_n=\sum_iX_i\), with Pauli operators. A depth-\(p\) QAOA state is
\[
 \psi_{n,p,J}=e^{-i\beta_pB_n}e^{-i\gamma_pC_{n,J}}\cdots
 e^{-i\beta_1B_n}e^{-i\gamma_1C_{n,J}}|+\rangle^{\otimes n}.
\]
For deterministic parameters, put \(v_p(\gamma,\beta)=\lim_n n^{-1}\mathbb E\langle\psi,C_{n,J}\psi\rangle\) and \(Q_p=\sup_{\gamma,\beta\in\mathbb R^p}v_p\). The claim is
\[
 \lim_{p\to\infty}Q_p=P_*,\qquad
 P_*=\lim_n n^{-1}\mathbb E\max_{\sigma\in\{\pm1\}^n}
 n^{-1/2}\sum_{i<j}J_{ij}\sigma_i\sigma_j.
\]
For each accuracy \(\varepsilon>0\), one finite depth and parameter vector, independent of both instance and size, achieves \(v_p\ge P_*-\varepsilon\). The size limit is taken first.
