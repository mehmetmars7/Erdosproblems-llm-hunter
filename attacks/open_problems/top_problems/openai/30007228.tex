For each fixed $S\in\{1/2,1,3/2,\ldots\}$, the claim provides finite \(\beta_0(S)\) so that any finite \(\beta\ge\beta_0\) has positive spontaneous magnetization \(m=p'_{S,\beta}(0+)\). With zero-field Gibbs expectation,
\[
 \lim_{L\to\infty,\ L\text{ even}}
 \left\langle\exp\!\left(V^{-1}\sum_{a=1}^3t_aM_L^a\right)\right\rangle_{\beta,L}
 =\frac1{4\pi}\int_{S^2}e^{m t\cdot n}\,d\sigma(n)
 =\frac{\sinh(m|t|)}{m|t|}\qquad(t\in\mathbb R^3).
\]
The value at \(t=0\) is one. The same limit gives \(V^{-2}\sum_{x,y}\langle\boldsymbol S_x\cdot\boldsymbol S_y\rangle\to m^2\).
