\section*{P vs. NP}\label{3395}
{\small UnsolvedMath ID 3395 · OPG-661 · Computer Science · OpenGarden}
\subsection{Definitions and mathematical statement}
A decision problem is a language $L\subseteq\{0,1\}^*$ of finite
binary strings. Its input size is the string length $|x|$. The class
$\mathrm P$ consists of languages decided by a deterministic Turing
machine in at most $C(|x|+1)^c$ steps for some fixed constants $C,c$.
The machine must halt and answer correctly on every input.

A language belongs to $\mathrm{NP}$ if there are a polynomial $p$
and a deterministic polynomial-time predicate $V$ such that
\[
 x\in L\quad\Longleftrightarrow\quad
 \exists y\in\{0,1\}^{\le p(|x|)}\quad V(x,y)=1.
\]
The string $y$ is a certificate for a yes-instance. Its length and
the verification time are bounded by fixed polynomials, uniformly
over all inputs. The problem is to decide whether
$\mathrm P=\mathrm{NP}$. Since $\mathrm P\subseteq\mathrm{NP}$,
inequality means exhibiting a language in $\mathrm{NP}$ with no
deterministic polynomial-time decision procedure.

The question uses the ordinary uniform, worst-case bit model of
computation. It does not permit a separate uncomputable advice string
for each input size or replacement by a quantum algorithm. Efficient
verification for no-instances is not part of the definition of
$\mathrm{NP}$. Polynomial-time solution of every input, rather than
success on a selected distribution of inputs, is required.
\subsection{Short English statement}
Does every decision problem with efficiently checkable yes-certificates also admit an efficient deterministic decision algorithm?
